# kancolle-iOS

iPhone / iPad向けの艦これプレイ補助アプリ試作です。

> **v0.1 は実機検証前です。イベント本番で使う前に、通常海域・キスクル等で表示と大破ブロッカーを必ず確認してください。**

## v0.1 の目的

- `Game` / `Info` の2タブ
- 1個の `WKWebView` で艦これを保持
- DMMログインCookieを標準Webデータストアへ保持
- 受信済み `kcsapi` を読み取り専用で解析
- 生のAPI履歴は保存せず、必要な情報だけSwift側へ渡す
- 艦隊HP・燃料・弾薬・搭載数を表示
- 連合艦隊の第1 / 第2艦隊表示
- 戦闘後HPから大破判定
- 判定不能時は安全側で進撃ロック
- 大破時にネイティブ通知・触覚警告
- 通常進撃 / 応急修理要員進撃 / 女神進撃を同じ大きなネイティブブロッカーで覆う
- ブロッカーを約2.4秒以内に3回タップした場合だけ5秒間解除
- WebKitプロセス終了を検出して自動復旧
- メモリ警告時も進撃判定中の戦闘後HPは破棄しない

## 設計方針

- ゲームサーバーへ独自の操作リクエストを送らない
- APIレスポンスを書き換えない
- 自動出撃・自動進撃・自動撤退を行わない
- 進撃解除後も、実際の進撃操作はユーザー自身が行う
- Webコンテンツ以外から艦これサーバーへ直接通信しない

## 必要環境

- Mac
- Xcode
- XcodeGen
- iOS / iPadOS 17以降の実機またはシミュレータ

XcodeGenが未導入ならHomebrewで以下を実行します。

```bash
brew install xcodegen
```

## Xcodeプロジェクトを作る

リポジトリを取得後、ルートディレクトリで以下を実行します。

```bash
xcodegen generate
open KancolleIOS.xcodeproj
```

## iPhoneへ入れる

1. iPhoneをMacへ接続
2. Xcodeで `KancolleIOS` ターゲットを開く
3. `Signing & Capabilities` で自分のTeamを選択
4. 実行先に自分のiPhoneを選ぶ
5. Runを押す
6. 初回のみiPhone側で開発者モード・署名の許可が必要な場合は案内に従う

## 最初の実機テスト

1. アプリを起動し `Game` タブでDMMへログイン
2. 母港を開く
3. `Info` タブでAPI取得数が増え、艦隊が表示されることを確認
4. 通常海域で1戦し、戦闘後HPの `*` 表示を確認
5. 中破・大破判定が実際のゲーム画面と一致することを確認
6. 大破時、左側の進撃系ゾーンへ赤いネイティブブロッカーが出ることを確認
7. 右側の撤退がブロックされていないことを確認
8. 赤い範囲を1〜2回タップしても解除されないことを確認
9. 3回タップすると5秒だけ解除されることを確認
10. **初回テストでは進撃せず撤退する**

## 表示値について

### HP

`*` 付きHPは戦闘APIから計算した戦闘後値です。

未知の戦闘形式・API解析失敗などで安全に判定できない場合は `判定不明` とし、進撃をロックします。

### 燃料・弾薬・搭載数

最後に艦これAPIから直接取得できた値です。戦闘中に独自推定して現在値を作ることはしません。

## メモリ対策

Safari版でページ再読み込みが発生したため、専用アプリ版では次を行っています。

- `WKWebView` を1個だけ保持
- APIレスポンス履歴を保存しない
- 必要なAPI以外はレスポンス本文をBridge側で読まない
- ゲーム領域の5秒ポーリングを行わない
- iOSのメモリ警告を受けたら不要な一時戦闘データを解放
- ただし進撃/撤退選択中のHPは安全のため保持
- WebKitプロセスが終了した場合は検知して再読み込み

## GitHub Actions

メール通知が連発しないよう、iOS Buildは **自動実行しません**。必要なときだけGitHubのActions画面から手動実行する `workflow_dispatch` 方式です。

## 注意

このアプリは非公式です。艦これ / DMM / WebKitの仕様変更で動かなくなる可能性があります。
